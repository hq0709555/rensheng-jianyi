# 给你点人生建议 · rensheng-jianyi

> 一个用于 **DeepSeek Harness** 的个人成长 skill：内置 **127 篇「老师日记 / 格物心法」人生认知文章**。当你迷茫、焦虑、内耗、纠结时，它会在语料里检索最相关的篇章，结合你的具体处境，给出有据可依的人生建议与思考——不是泛泛而谈的鸡汤，而是能指出「哪一篇、哪句话」支撑它的判断。

## ✨ 它能做什么

1. **理解处境** —— 先点破你「表面问题」与「底层问题」，不急着堆大道理。
2. **检索语料** —— 按标题 + 正文关键词，在 127 篇文章里定位最相关的 1–3 篇并精读。
3. **结合处境给建议** —— 用「点题 → 分析 → 可行动建议」的结构，把语料里的观点套到你的具体情况上。
4. **标注出处** —— 结尾列出用到的文章标题与关键原句，方便你回去翻原文。

## 📚 语料规模

- **127 篇文章 · 约 2241 页 · 73 万字**，全部为中文人生认知内容
- 来源为图像型 PDF，经 macOS Vision 框架 OCR 转成 Markdown，存于 `corpus/`
- 配套 `index.md` 主题索引，把 127 篇归入 **10 大主题**：认知觉醒、情绪内耗、财富赚钱、职场事业、人性处世、社交关系、婚姻亲密、家庭亲子、自我成长、贵人资本

## 🚀 使用

困惑时直接说，skill 会自动匹配加载，例如：

- 「最近很焦虑，总静不下心，怎么办？」
- 「同事总把活推给我，我不好意思拒绝，很憋屈。」
- 「不知道该不该辞职，纠结很久了。」
- 「和父母一说话就烦躁，是不是我太不孝了？」

**触发词**：人生建议、我该怎么办、迷茫、困惑、想不通、焦虑、内耗、纠结、认知、觉悟、格局、人性、处世、社交、职场、赚钱、婚姻、亲密关系、自我成长、低谷、改命。

### 效果示例

> 用户：最近总忍不住刷手机，一刷就是几小时，刷完又空虚又焦虑，怎么破？

> skill（节选）：先点题——你刷的不是手机，是「用别人的生活，替换掉自己的时间」。语料里《刷手机的本质是放弃自己的生活转向别人的生》讲的就是这个：刷手机是低成本地消费别人的人生，代价是把自己的主线让渡出去。给你三条能落地的：① 把「打开 App」换成「打开记录本」，高频记录自己；② 给刷手机设一个「目的」，没有目的不点开；③ 用「熵增」视角看待碎片时间——不管理它，它只会越来越乱。参考语料：《刷手机的本质…》《一定要高频深度地记录自己》《自从知道「熵增」这个概念，我再也不玩手机》。

## ⚠️ 边界

- 语料是「角度与认知」，不是真理；skill 会尽量忠实于语料，并标注哪些来自原文、哪些是延伸。
- 医疗、法律、投资等专业决策，只给心智层面的思考，会提示你咨询专业人士。
- 不替你做离不离婚、辞不辞职这类重大决定，而是给思考框架和利弊角度。
